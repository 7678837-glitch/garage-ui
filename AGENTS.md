# Repository rules

## Language

English is the primary language of this repository. Write everything in English: code comments, log and error messages (startup errors included), UI copy, documentation, commit messages, and pull request text. The only Chinese documentation is `README.zh-CN.md`, a companion Simplified Chinese translation of `README.md`; update it whenever `README.md` changes.

Do not add new Chinese text. Chinese that still exists is pending translation. Two kinds of Chinese stay: test data that exercises non-ASCII handling, such as Chinese object names, and the Simplified Chinese UI locale catalog that spec 6.7 requires. `README.zh-CN.md` also stays, as described above.

## CI

The GitHub Actions workflow is disabled on GitHub until development is finished. Do not re-enable it.
